# 庄方宜：已完成工作流的有限示例

本目录仅含一张最终预览、独立人物/中文对话节点、两条原创日语台词和来源清单，不包含官方立绘、音频、用户眼部截图、密钥、音色绑定或聊天记忆。

![庄方宜最终设计预览](preview.png)

预览为1920×1080、2350400字节，低于3MiB。它使用明确的示例余额与终端文字，气泡是同源baked RGBA静态2D材质检查；不是实时桌面或GPU渲染截图。原运行时3D弹簧交互不由这张图证明。

[批准资产清单](assets-manifest.json)记录尺寸、SHA256与预览边界。[角色来源与眼色锁定](source-notes.json)记录当前官方资料及用户修正。persona.json与dialogue.json为单角色节点，导入时按目标端契约合并，不覆盖用户原有角色数据与设置。
